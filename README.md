# UTS_PWEB_252410103072

LEVELUP merupakan website berbasis Laravel yang dirancang sebagai sistem informasi pengelolaan toko game. Website ini membantu pengguna dalam melihat katalog produk game, memantau harga dan diskon, serta mengetahui ketersediaan stok produk.

Website ini memiliki beberapa halaman utama :

Halaman Login – Digunakan untuk memasukkan username sebelum mengakses website.
<img width="1919" height="965" alt="image" src="https://github.com/user-attachments/assets/202dfb65-9b26-41eb-b366-e2b7175af325" />


Halaman Dashboard – Menampilkan informasi ringkas mengenai jumlah produk, stok yang perlu diisi ulang, nilai stok, serta produk yang sedang mendapatkan promo.
<img width="1918" height="963" alt="image" src="https://github.com/user-attachments/assets/e81367d2-8463-4b04-b8b0-f366077e0962" />


Halaman Pengelolaan Produk – Menampilkan daftar produk beserta kategori, platform, harga, diskon, jumlah stok, dan status ketersediaannya. Pengguna juga dapat memfilter produk berdasarkan kategori.
<img width="1919" height="872" alt="image" src="https://github.com/user-attachments/assets/ed6f3270-fa5d-453c-8873-52e3da23a2c6" />


Halaman Profil – Menampilkan informasi akun pengguna, seperti nama akun, jabatan, cabang, shift kerja, dan waktu login terakhir.
